```json
{"version": 1,
 "shape": [nz, ny, nx],                 // == Case.volume.shape (packed)
 "spacing": [sz, sy, sx],               // == Case.volume.spacing, mm
 "zones": {
   "pancreas": [1],                      // organ zone: mask VALUES (uint8 pack) → dilate by rules.organ_dilation_mm, fill holes
   "superior_slab": "slab:superior",     // z in [0, nz//3)
   "mid_slab": "slab:mid",               // z in [nz//3, nz - nz//3)
   "inferior_slab": "slab:inferior",     // z in [nz - nz//3, nz)
   "right_half": "half:right",           // x < (nx-1)/2 - midline_frac*nx   (patient RIGHT = low x)
   "left_half": "half:left",             // x > (nx-1)/2 + midline_frac*nx
   "midline_volume": "half:midline"      // |x - (nx-1)/2| <= midline_frac*nx
 },
 "rules": {"organ": "...", "organ_dilation_mm": 5.0, "slab": "...", "half": "...", "midline_frac": 0.1, "patient_right_is_low_x": true}}
```
Abdomen cases (Task07 / Task08) carry the organ zone their task labels (`pancreas` → [1]; `hepatic_vessels` → [1]; no `liver` zone exists for Task08, there is no liver mask) plus the three slab thirds and the three halves. Brain cases carry `brain_right: "half:right"`, `brain_left: "half:left"`, `brain_midline: "half:midline"` plus the slab thirds (no organ values). Zone masks are DEFINED, not stored: organ zone = `np.isin(mask, values)` → `binary_dilation` with a spacing-aware ellipsoid of radius `organ_dilation_mm` → `binary_fill_holes` (`pipeline.volumetric.geometry.organ_zone_mask` is the reference implementation; `third_ranges` / `half_mask` for the others).
