## Contracts (frozen after M0)
- `shared/schemas/*.json` — case, finding, telemetry_event, attempt_submit, submit_result, debrief_facts, debrief_output, debrief_response, teaching_card, api ($defs for the small shapes).
- `shared/contracts.py` — Pydantic mirrors; imported by backend, pipeline, eval, tutor. `shared/tests/test_contracts.py` checks models ↔ schemas.
- `frontend/src/types/contracts.ts` — generated by `npm run gen:types` (json-schema-to-typescript). Never hand-edit.
- Change process: `CONTRACT CHANGE REQUEST:` in PROGRESS.md → orchestrator edits `shared/` and regenerates.
- Decisions baked in: finding/mark ids in API responses are SHORT ids (`F1`, `M1`); outcomes carry `matched` + `learner_label`; `NextCase` carries `hints_enabled` + `done`; `DebriefResponse.status` adds `disabled`; `source: synthetic` allowed for test fixtures (`syn_` ids).
